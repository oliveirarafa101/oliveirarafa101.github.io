# Rafael Oliveira · Portfolio

Personal portfolio featuring TruckMotion, Integrated Systems Framework, Critical TechWorks and Paradigma X STCP.

**Website:** [oliveirarafa101.github.io](https://oliveirarafa101.github.io)

## Run locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. The site uses plain HTML, CSS and JavaScript, with no package installation or build step.

## Edit

- `index.html`: homepage and contact links
- `styles.css`: responsive styling
- `app.js`: project details and interactions
- `assets/`: favicon and original thesis architecture diagrams

## Publish

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the website. The `.nojekyll` file ensures GitHub serves the static files directly.

The diagrams and project descriptions belong to this portfolio. The repository contains no source code from the featured applications.
