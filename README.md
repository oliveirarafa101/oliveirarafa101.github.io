# Rafael Oliveira · Portfolio

Personal portfolio featuring TruckMotion, Integrated Systems Framework, Critical TechWorks and Paradigma X STCP.

**Website:** [oliveirarafa101.github.io](https://oliveirarafa101.github.io)

Includes English and Portuguese copy, a persistent light/dark theme, career history, education, an architecture gallery and a printable résumé.

## Run locally

```sh
python3 -m http.server 8080
```

Open http://localhost:8080. The site uses plain HTML, CSS and JavaScript, with no package installation or build step.

## Edit

- `index.html`: homepage and contact links
- `styles.css`: responsive styling
- `enhancements.css`: portrait, career timeline, gallery and theme styles
- `app.js`: project details and interactions
- `i18n.js`: Portuguese copy and language preferences
- `resume.html`, `resume.css`, `resume.js`: printable professional profile
- `assets/`: portrait, favicon and original thesis architecture diagrams

## Publish

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the website. The `.nojekyll` file ensures GitHub serves the static files directly.

The diagrams and project descriptions belong to this portfolio. The repository contains no source code from the featured applications.

## Content notes

Career and education details were checked against the 2026 CV. The TeamViewer entry does not include dates because the CV gives conflicting start dates. The résumé includes professional information, without the original CV's phone number or date of birth.

The original thesis diagrams remain in their original language. Interface text and project descriptions are available in English and Portuguese.
